How to use this list

Type to search by name, description, or tag — matches don't need to be an exact or contiguous substring, just the letters in order. Click any tag to filter by it; combine multiple tags to narrow further, and click the × on a selected tag to remove it. "Show tags" lists every tag in the collection, to browse instead of search. "Sort alphabetically" switches the result order from best-match-first to A–Z. "Reset" clears the search box and all selected tags.
